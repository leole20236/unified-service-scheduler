Every booking must hold one bay + one qualified technician for the whole job · 2

(~20s) Each booking needs one bay and one technician for the whole job, and neither can ever be double-booked. To design the system, I made some assumptions: around twenty thousand dealer sites, so about ten thousand reads and a thousand writes per second at peak. Most traffic is reads, so I use caching. Conflicts only happen inside one dealership, so a database rule is enough.
