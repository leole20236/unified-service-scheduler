(~25s) Here's the full design. Users go to their own region: EU, US or Asia. Each region has its own copy of the system and shares no data. Inside a region, the gateway checks who you are. The scheduler runs on Kubernetes. PostgreSQL stores the bookings, Redis makes it fast, and events go to a message broker for emails and reports.
